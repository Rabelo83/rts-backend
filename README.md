# RTS Backend

This repository hosts the Gainesville RTS realtime + schedule backend and the accompanying web UI.

## Live Sites

- **Main tracker:** https://rts-backend-7ru5.onrender.com/
- **Standalone chat assistant:** https://rts-backend-7ru5.onrender.com/chat

Use the chat page to interact with the guided RTS assistant in its own window, or open the chat bubble from the main tracker UI.
